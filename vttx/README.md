# VTTX-MVD (Minimum Viable Demo)

**Part of XMFB Reflex UI System**  
Chrome + React + Tailwind scaffold for presence-based communication.

---

## 🧬 Core Features

- Splash screen with `%smash-tag:½` CMID & FeedSig ritual
- Cam permission + setup screen
- ReflexGrid with 3x3 layout and presence mapping
- VTTXWindow with real-time AI log, chat feed, agent list
- VTTXAlert pop-up for incoming reflective interactions
- Global AppContext + reducer-based state
- Hooks for agent presence, AI operator, smash-sync
